# ForMaT pilot

`data/benchmarks/format/ForMaT_Dataset.zip` is the dataset catalog from https://huggingface.co/datasets/laniqo/ForMaT. It contains metadata and links, not PDFs. `python -m benchmarks.format.prepare` fetches English source PDFs, validates their hashes, page count and native text, and saves a resumable manifest. Selection is seeded and limited to 100 pages and 15 MB per PDF. Original documents have their own rights; review those before redistribution. The collection is opportunistic, not a representative sample, and some original links fail. No reference PDFs are currently downloaded.

Run the four-document pilot with `.venv/bin/python -m benchmarks.format.pilot --out output/benchmarks/format-pilot-new`. It selects short PDFs, preferring different source publishers, uses Hindi and auto layout, creates an isolated Studio database for each case, and calls a source-only visual judge via OpenRouter. The test makes real provider calls and may incur costs. Source and candidate pages are sent to the judge. Results include translation status, Studio issues, judge response, candidate PDF, and localized judge hypotheses. No reference translation exists for Hindi in ForMaT. Scores and findings are unverified; a high score may coexist with reported issues. Verify findings on page images before making changes. A failure of one case is recorded and does not stop others.

This initial pilot does not yet provide frozen-translation replay, holdout selection, systematic before/after comparison, or reliable cost totals. Preserve the selection and outputs for future comparisons.

## Balanced source collection

`data/benchmarks/format/balanced-manifest.json` contains 100 distinct verified English PDFs: 36 UN, 25 Nissan, 25 Toyota, 7 Philips, 4 Lenovo and 3 Huawei. Recreate or extend with `python -m benchmarks.format.balanced`. This is a source-quota convenience sample, not a random sample and not balanced across page counts: many automotive manuals are hundreds of pages. Original catalog links for EUR-Lex, European Parliament and US Social Security were unavailable during collection. The dataset is 36 legal and 64 instructions documents; count each document, not each page, when sampling. The 12-page maximum in the pilot accepts only 36 UN and 3 Lenovo PDFs from this manifest. A representative pilot needs a documented page-sampling strategy for longer manuals; do not silently truncate them or claim the short-document filter is balanced. `--manifest data/benchmarks/format/balanced-manifest.json` selects this collection explicitly, and `--max-pages` can be set up to 12.
